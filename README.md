# nand-kitty-rice

A CachyOS/Arch setup where fastfetch greets you on every new shell with an
illustrated two-column layout: the artwork on the left, 24 hand-cut icons next
to each information line, arranged in two balanced columns.

Symptoms of the layout working: fastfetch runs automatically when a shell
starts, the girl is on the left with no white box around her, and every row has
its own icon that is vertically centred on the text.

## What's inside

```
fastfetch/
  config.jsonc            plain `fastfetch` config (single column, keyIcon escapes)
  fetch.py                two-column renderer used by the fish greeting
  icons/*.png             24 icons cut from an icon sheet, 540x600 (6x3 cells)
  logo.png                artwork, cut out with its own alpha (583x1533)
  tools/extract_icons.py  regenerates icons/*.png from the source sheet
kitty/
  kitty.conf              opacity / padding / cursor trail + theme include
  themes/noctalia.conf    colour scheme (regenerated by Noctalia on wallpaper change)
fish/
  config.fish             greeting override -> fastfetch/fetch.py
```

## Install

```sh
git clone https://github.com/Black-sys-dot/nand-kitty-rice.git ~/dotfiles
ln -sfn ~/dotfiles/fastfetch ~/.config/fastfetch
ln -sfn ~/dotfiles/kitty    ~/.config/kitty
ln -sfn ~/dotfiles/fish     ~/.config/fish
```

Requires `fastfetch` (built with image support) and `kitty` (graphics protocol).
The images are drawn with the kitty graphics protocol, so icons only appear in
kitty/ghostty/wezterm-class terminals; anywhere else `fetch.py` prints the same
table without pictures, and plain `fastfetch` falls back to the single-column
layout.

## How the renderer works

`fastfetch` cannot put modules in columns, so `fetch.py` runs it with a control
character as the key/value separator, then lays the result out itself:

- 12 entries per column, each icon occupies 6 cells x 3 rows
- the icon is drawn one row above its text so the text sits at the icon's
  vertical centre (that off-by-half-a-cell is what makes rices look "off")
- the whole composition is centred using the real terminal width, with a
  single-column fallback under ~136 columns
- icons are re-read from disk on every run, so no caching surprises

Tuning knobs live at the top of `fetch.py`: `LOGO_CELLS`/`LOGO_ROWS` (artwork
size, keep the ratio ~0.87), `LOGO_GAP`, `COL_GAP`, `ICON_COLS`/`ICON_ROWS`,
`LOGO_SHIFT`.

## Regenerating the icons

```sh
python3 ~/.config/fastfetch/tools/extract_icons.py /path/to/icon-sheet.png
```

The extractor finds each icon's bounding box with ImageMagick
connected-components, drops the printed captions, crops every icon to the exact
cell aspect so they all render the same size, and zeroes the RGB hidden under
transparent pixels (otherwise the compositor blends it through and you get a
white halo).

## Notes

- `config.jsonc` and `fetch.py` contain absolute `/home/black/...` paths; edit
  them if you clone this under a different user.
- `fish_variables` is deliberately ignored: it is machine state, not dotfiles.
